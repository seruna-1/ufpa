# Missão 3: multiplicação matricial

## Cenário

A equipe faz parte de uma equipe de desenvolvimento responsável por otimizar uma aplicação científica que realiza multiplicação de matrizes de grandes dimensões.

## Problema

Atualmente, a aplicação funciona de maneira sequencial. Entretanto, conforme o tamanho das matrizes aumenta, o processamento exige cada vez mais tempo.

## Objetivo

Usar a biblioteca OpenMP para otimizar a multiplicação matricial pela divisão de trabalho em threads.
