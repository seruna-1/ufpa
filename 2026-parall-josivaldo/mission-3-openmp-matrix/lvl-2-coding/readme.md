# Nível Prata: Implementação

## Objetivo

 1. Implementar a paralelização das regiões identificadas, utilizando diretivas OpenMP adequadas à estratégia proposta.

 1. Configurar a aplicação para executar com múltiplas threads, explicando como a quantidade de threads foi definida e controlada.

 1. Documentar as principais modificações realizadas no código, identificando as diretivas OpenMP utilizadas e justificando suas escolhas.

 1. Realizar testes funcionais comparando os resultados produzidos pelas versões sequencial e paralela, utilizando diferentes quantidades de threads.

 1. Verificar se a paralelização preservou a correção dos resultados, explicando como foram evitadas possíveis condições de corrida e problemas relacionados ao compartilhamento de dados.

Observação: a análise de desempenho fica para o próximo nível.
